# Technical implementation - Bachelor thesis
This repo contains the proof of concept of my bachelor thesis. The thesis itself is also included in this repository.
The created system started with the tool GazeTracking, created by Antoine Lamé. Then during my thesis I refactored, implemented new features and more to truly make it my own tool. A full explination with technical details can be read in my thesis. Along with the journey how it was created.
The goal of the system is to track the users eyes and moves the mouse based on gaze estimation calculations. When blinking, the user will perform a mouse click-action
